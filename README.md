# UAE FDI Resilience Analysis (2025–2026)

This repository contains a scenario-based assessment of UAE Foreign Direct Investment resilience under varying global financial and energy conditions.

## Key Findings

- FDI momentum strengthened materially in 2023–2024.
- Short-term volatility remains linked to global liquidity and oil prices.
- Structural positioning supports sustained inflows beyond cyclical normalization.
- A strategic anchor-heavy baseline (w = 0.3) implies elevated 2025 inflows with gradual moderation in 2026.
